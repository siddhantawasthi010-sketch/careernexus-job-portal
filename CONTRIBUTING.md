# Contributing

## Development workflow

1. Create a feature branch from `develop`
2. Implement the change in isolation
3. Commit with a clear message
4. Push the branch to the remote repository
5. Open a pull request to `develop`
6. Wait for review and approval
7. Merge only after checks pass

## Branch naming

Use descriptive feature names:

- `feature/auth`
- `feature/jobs`
- `feature/candidate-dashboard`
- `feature/recruiter-management`

## Protected branches

- `main` is protected and requires pull request review
- `develop` is the integration branch for ongoing work

## Git hosting

Use GitHub, GitLab, or Bitbucket with branch protections enabled.
